Where each observation was measured

Each SPHEREx detector covers part of 0.75–5.0 µm, and the wavelength at a star depends on where it lands. Only observations stacked vertically (same wavelength) can be compared for brightness.

Static preview · results precomputed by the Skytrace pipeline; nothing is contacted while you browse. What this means

Every result here was produced by the Skytrace server and Python pipeline when this preview was built, from the bundled synthetic test targets. While you browse, no server, archive or language model is contacted. Re-runs offer the precomputed parameter sets (defaults and the five stability perturbations); pair comparisons and image registration are computed in your browser from the record; anything that needs the server says so. Run python run.py for the full application.
